# PT Report Class

**Version:** 0.3<br>
**Date:** 2026/08/29<br>
**Author:** Pedro Toledo Correa  
**License:** LaTeX Project Public License 1.3c or later  
**Repository:** [GitHub - ptoledo-teaching/pt-report](https://github.com/ptoledo-teaching/pt-report)

A professional LaTeX report document class built on top of `pt-commons`, designed for technical reports, project documentation, and academic assignments. Features single-column layout with section page breaks and enhanced formatting capabilities.

## Overview

`pt-report` extends the standard LaTeX `article` class with:
- Professional single-column layout with 63pt margins
- Custom title page generated with `\maketitle`
- Version and build information in the footer
- Section page breaks (each section starts on a new page)
- Enhanced section formatting
- Highlight boxes for important content
- Optional watermark support
- All default features from the `pt-commons` package

## Installation

Install `pt-report.cls` and all `pt-commons*.sty` files in your LaTeX project
or texmf tree:

```bash
# Local installation
mkdir -p ~/texmf/tex/latex/pt-report
mkdir -p ~/texmf/tex/latex/pt-commons
cp pt-report.cls ~/texmf/tex/latex/pt-report/
cp pt-commons*.sty ~/texmf/tex/latex/pt-commons/
texhash ~/texmf
```

## Basic Usage

```latex
\documentclass{pt-report}

\title{Your Report Title}
\addauthor{John}{Doe}{john.doe@example.com}{University Department}

\begin{document}
\maketitle

\section{Introduction}
Your content here...

\section{Methodology}
Each section starts on a new page...

\end{document}
```

## Class Options

### Language Options (from pt-commons)

```latex
\documentclass[english]{pt-report}    % English
\documentclass[spanish]{pt-report}    % Spanish (default)
\documentclass[portuguese]{pt-report} % Portuguese
\documentclass[french]{pt-report}     % French
```

### Code Environment Options

```latex
\documentclass[nominted]{pt-report}  % Disable minted, use verbatim
```

### Advanced Shared-Module Options

Use `ptnolayout`, `ptnocontent`, or `ptnoruntime` to disable optional
`pt-commons` modules. `coreonly` (or `minimal`) disables all three, and the
namespaced positive options can restore selected functionality without leaking
generic option names to other LaTeX packages:

```latex
\documentclass[coreonly]{pt-report}
\documentclass[coreonly,ptcontent,nominted]{pt-report}
```

The individual pairs are `ptlayout`/`ptnolayout`, `ptcontent`/`ptnocontent`,
and `ptruntime`/`ptnoruntime`. When loading `pt-commons` directly as a package,
use its native unprefixed module options instead.

Commands supplied by a disabled module are intentionally unavailable. Packages
used directly by the report class remain loaded.

### Font Size and Page-Side Options

The default is a 12pt, one-sided report. `twoside` reserves the back of the
title page as page 2 and begins the report content on page 3:

```latex
\documentclass[10pt]{pt-report}   % 10pt font
\documentclass[11pt]{pt-report}   % 11pt font
\documentclass[12pt]{pt-report}   % 12pt font (default)
\documentclass[oneside]{pt-report} % Title page 1; content starts on page 2
\documentclass[twoside]{pt-report} % Title page 1; blank page 2; content starts on page 3
```

`pt-report` is deliberately a single-column class. The `twocolumn` option is
not supported; use `pt-article` for a two-column document. The class also always
uses a dedicated title page, so `notitlepage` is not supported.

## Document Metadata

### Title and Authors

```latex
\title{Main Title}
\titlesub{Optional Subtitle}
\titlesubsub{Optional Sub-subtitle}
\date{2026-08-29} % Optional; the current date is used when omitted

% Add multiple authors
\addauthor{FirstName}{LastName}{email@example.com}{Affiliation}
\addauthor{Jane}{Smith}{jane@university.edu}{Department of CS, University}

% Optional: Add logo
\logo{path/to/logo.png}
```

The title page generated by `\maketitle` includes:

- Logo (if specified)
- Title hierarchy
- Academic/class metadata
- Date and version, when applicable
- Institutional or corporate metadata
- An author table with emails and affiliation/details

The author table is right-aligned and uses its natural width when it fits.
Oversized names, emails, or affiliations expand to a wrapping table without
leaving an empty trailing row.

The title page is produced only when `\maketitle` is called. If `\date` is
omitted, the current localized date is printed automatically. Use `\date{}` to
suppress it. A non-empty `\version{...}` is printed automatically next to the
date.

### Version Control

```latex
\version{1.0}              % Set document version
\build{auto}               % Increment when a tracked source changes
\buildsource{chapter.tex}  % Optionally track an included source
\watermark{DRAFT}          % Add watermark
```

With the shared layout module enabled, the footer displays the page number and
one of the following status lines:

- `v1.0 - 2026/08/29` when only a version is set
- `B5 - 2026/08/29` when only build 5 is set
- `v1.0.5 - 2026/08/29` when version 1.0 and build 5 are both set

The date in the footer is generated automatically at compilation time. With
`ptnolayout`, the class uses a minimal footer containing only the page number.

### Academic Information

### Institutional Information


For corporate reports, use the current corporate metadata commands instead of
the institutional hierarchy:

```latex

```

## Page Layout

The class uses standard report layout with comfortable margins:

- **Page margins:** 63pt (approximately 0.87in) on all sides
- **Paragraph indentation:** 42pt (approximately 0.58in)
- **Single-column layout**
- **Section breaks:** Each section starts on a new page

In the default `oneside` mode, the title page is page 1 and the following
content starts on page 2. In `twoside` mode, page 2 is intentionally blank so
the content starts on the next recto page, page 3.

### Geometry

```latex
% Automatically configured:
% - Letter paper size (default)
% - 63pt margins (left, right, top, bottom)
% - Footer included in layout
```

## Section Formatting

The class provides standard section formatting with automatic page breaks:

```latex
\section{Section Title}           % Starts on new page
\subsection{Subsection Title}     
\subsubsection{Subsubsection}     
\paragraph{Paragraph Title}       
```

**Important:** Each `\section` or `\section*` starts on a new page, making
reports easy to navigate and organize.

## Enhanced Features (from pt-commons)

### Highlight Boxes

```latex
\begin{highlightbox}
Important content that needs emphasis.
\end{highlightbox}
```

### Code Listings

```latex
% Inline code
Use \inlinecode{variable_name} for inline code.

% Code blocks (Minted when available)
\begin{ptprintcode}{python}
def hello_world():
    print("Hello, World!")
\end{ptprintcode}

% The same API uses a verbatim fallback with the nominted option
\begin{ptprintcode}{python}
def hello_world():
    print("Hello, World!")
\end{ptprintcode}
```

### Tables

```latex
% PT table columns wrap their contents within the configured width
\begin{tblr}{colspec={|X[l]|C{0.22\linewidth}|R{0.18\linewidth}|}}
    \hline
    \tableheader
    Left & Center & Right \\
    \hline
    \hline
    Data & More & Values \\
    \hline
\end{tblr}
```

A standalone `tblr` is treated as a display and receives one collapsible
`\medskipamount` of vertical separation before and after it. Inside `table` or
`table*`, the class leaves spacing to the float and caption mechanisms so it is
not applied twice.

### Figures

```latex
\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.8\textwidth]{image.png}
    \caption{Figure caption}
    \label{fig:example}
\end{figure}
```

### Mathematics

```latex
% Inline math
The equation $E = mc^2$ is famous.

% Display math
\begin{equation}
    \int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
\end{equation}
```

## Lists of Contents

```latex
\tableofcontents          % Table of contents
\ptlistoffigures         % List of figures (if any)
\ptlistoftables          % List of tables (if any)
\ptlistofcodes           % List of code listings (if any)
```

The `pt*` commands produce a list only when numbered/captioned entries of the
corresponding type have been registered. A plain `tblr` or `ptprintcode` block
does not create a list entry by itself.

## Watermark

Add a watermark to all pages (useful for drafts):

```latex
\watermark{DRAFT}         % Add "DRAFT" watermark
\watermark{CONFIDENTIAL}  % Add "CONFIDENTIAL" watermark
```

The watermark appears diagonally across each page in a light red color.

## Complete Example

```latex
\documentclass[spanish]{pt-report}

% Document metadata
\title{Informe Técnico del Proyecto}
\titlesub{Sistema de Gestión de Datos}
\titlesubsub{Versión Final}
% \date{2026-08-29} % Optional; omitted means the current date

% Version control
\version{1.0}
\build{auto}

% Authors
\addauthor{Juan}{Pérez}{juan.perez@universidad.cl}{Departamento de Informática}
\addauthor{María}{González}{maria.gonzalez@universidad.cl}{Centro de Investigación}

% Academic info
\classcode{IWI-131}
\classname{Programación}
\classsemester{Primer Semestre 2026}

% Institution info
\department{Departamento de Informática}
\school{Escuela de Ingeniería}
\university{Universidad Técnica Federico Santa María}

\begin{document}

\maketitle

\tableofcontents
\ptlistoffigures
\ptlistoftables

\section{Introducción}

Este informe presenta el desarrollo completo del proyecto...

\subsection{Objetivos}

Los objetivos principales son:
\begin{itemize}
    \item Desarrollar un sistema robusto
    \item Implementar las mejores prácticas
    \item Documentar todo el proceso
\end{itemize}

\section{Marco Teórico}

El marco teórico establece las bases conceptuales...

\begin{highlightbox}
Concepto importante: La arquitectura del sistema sigue...
\end{highlightbox}

\section{Metodología}

La metodología empleada consta de las siguientes etapas...

\section{Resultados}

Los resultados obtenidos demuestran...

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.8\textwidth]{results.png}
    \caption{Resultados experimentales}
    \label{fig:results}
\end{figure}

\section{Conclusiones}

En conclusión, el proyecto ha cumplido con los objetivos...

\end{document}
```

## Tips and Best Practices

1. **Organization:** Use the automatic section page breaks to organize your report into clear, digestible chunks.

2. **Version Control:** Set a version number and use `\build{auto}` to track source revisions. The date and resulting version/build status are formatted automatically.

3. **Watermarks:** Use watermarks for drafts and remove them for final versions.

4. **Tables:** Keep tables concise and use `\footnotesize` if needed (automatically applied in tblr environment).

5. **Code Listings:** Prefer `minted` for syntax highlighting unless compilation time is an issue.

6. **Figures:** Always use descriptive captions and labels for cross-referencing.

7. **Lists of Contents:** Only include lists that are relevant to your report content.

## Troubleshooting

### Sections not breaking to new pages

Both `\section` and `\section*` start with a page break. If that does not
happen, verify that another package or a later preamble command has not replaced
the class definition of `\section`.

### Watermark not appearing

Ensure you have the `draftwatermark` package installed and properly configured in `pt-commons`.

### Build counter not incrementing

The state is stored in a job- and version-specific `.buildcount` file. Automatic
mode advances only when a tracked source changes. Check write permissions and
register included sources with `\buildsource{...}` when needed.
